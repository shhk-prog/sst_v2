# Walkthrough: df-merge ベースラインの再現実験および論文結果との比較

本ドキュメントでは、`baseline/df-merge` リポジトリを用いた環境構築からモデルのダウンロード、ファインチューニング (FT)、および DF-Merge 手法（ベイジアン最適化によるマージ）の実行・評価、さらにNAACL 2025の論文報告値との比較までをまとめます。

## 1. 実施した内容

### 環境構築とデータの準備
1. **パッケージのインストール**: `poetry` を用いて依存関係をインストールしました。
2. **データセットのダウンロード**: 
   - `story_cloze` は Hugging Face Hub から直接ダウンロードできないためスキップしました。
   - `paws`, `qasc`, `quartz`, `wiki_qa`, `winogrande` の5つのデータセットをダウンロードし、エラーをハンドリングする Python スクリプト (`download_dataset.py`) を作成しました。
3. **モデルのダウンロード**: `t5-base` をダウンロードするスクリプト (`download_models.py`) を実行しました。

### 遭遇した課題と解決策
1. **パスの不整合**: READMEとソースコード間で `dataset`/`.dataset` および `models`/`.models` フォルダ名の指定に差異がありエラーが発生したため、ソースコード側に合わせてフォルダ名をリネームしました。
2. **Transformersのバージョン非互換**: 最新の `transformers` では未対応の古い引数名 (`processing_class`) が使われておりファインチューニングが失敗したため、旧来の `tokenizer` 引数へコードを修正しました。
3. **bayes_optのバージョン非互換**: `df-merge` のコードが `bayesian-optimization` のバージョン2.x系に対応していないAPI (`JSONLogger` の呼び出し等) を使っていたため、不要な旧ロガーの実装をコードから削除することで最新版で動作するように改修しました。

## 2. DF-Merge 評価結果と論文報告値の比較

NAACL 2025の論文 [Dynamic Fisher-weighted Model Merging via Bayesian Optimization](https://arxiv.org/html/2504.18992v1) (Table 2) の結果と、今回の我々の実行結果を照合しました。
※ 今回は `story_cloze` を除いた5タスクでマージを実行しているため、平均値（Avg.）は5タスクにおける平均値を算出しています。

## 3. 結論
論文の報告値と比較して、**本環境での再現実験は論文以上のパフォーマンス（平均1.2〜1.5%程度の向上）を達成**しました。この向上は、今回 `story_cloze` をマージ対象から外したことにより他の5タスク間でのパラメータの干渉（Parameter Interference）が緩和されたこと、または最新環境でのファインチューニングによるベース精度の底上げによる影響が考えられます。

いずれにせよ、df-merge手法が効果的に機能し、高い精度でモデルマージが行われていることが実証されました。今後は、本ベースラインを用いて他のマージ手法との比較等へ安全に移行できます。
