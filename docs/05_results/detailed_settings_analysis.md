## 📊 総括

### 主要な発見

1. **DARE**: 非常に不安定で、SST-Mergeと比較して大幅に劣る性能
2. **補間型**: k=5固定、GEVP×layerwiseの4設定が存在
   - GEVP無効時: 高いJailbreak耐性（最大100%）、低いUtility
   - GEVP有効時: バランスの取れた性能
3. **Data-Free**: **k値とlayerwiseの影響を一切受けない**（要調査）

### 推奨設定

**最良バランス（補間型）**:
- **A5_A7**: k=5, GEVP=True, layerwise=True, α=0.1
  - Jailbreak: 67.80%, RepliQA: 67.32%
- **A6_A7**: k=5, GEVP=True, layerwise=True, α=0.1
  - Jailbreak: 76.00%, Alpaca: 70.59%

**最高Jailbreak耐性（補間型）**:
- GEVP=False, α=1.0で100%達成可能
