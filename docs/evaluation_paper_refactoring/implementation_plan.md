# 目標

`flmsec_standalone.tex` を提案論文の形式から評価論文の形式へリファクタリングし、査読者の懸念（Validity判定の根拠、評価指標の混同、SSTの優位性の主張）を払拭する。

## User Review Required

以下の点について確認をお願いします。

- **再分類件数 ($N$, $M$, $K$) の穴埋め**: 「Original ASRのみでは安全改善と解釈された$M$条件のうち、$K$条件が再分類された」という箇所は、現状のデータで具体的な数値を埋めることが難しければ、プレースホルダーとして `$N, M, K$` のまま出力し、後で手動で埋めていただく形にしますが、それでよろしいでしょうか？（可能な限り表1等から計算を試みます）
- **Validity判定のアブレーション**: 今回は「可能な限り」ということで付録に代表的な手法でのアブレーション結果用の枠（プレースホルダー表など）を用意し、本文から言及する形にしますがよろしいでしょうか？

## Proposed Changes

### [MODIFY] `flmsec_standalone.tex`

1. **Terminology の統一（冒頭に追加）**
   - 論文冒頭（Introduction または 評価について の冒頭）に、以下の箇条書きを追加し、原稿全体の該当箇所を置換します。
     - **Original ASR**: 全応答を対象に既存評価器で算出する従来のASR。
     - **Valid Response Rate (VRR)**: 全応答に占める有効応答の割合。
     - **Conditional ASR**: 有効応答に限定して算出する有害追従率。（※Filtered ASR から変更）
     - **Valid Safety Rate (VSR)**: 全応答に占める「有効かつ非追従」の割合。

2. **Validity判定規則の厳密化（本文＆付録）**
   - 「評価について」の章（または適切な箇所）に `\paragraph{Validity判定規則}` を追加し、指定された(i)〜(iv)の基準と、人手確認の方針（「代表例のみの定性的確認」）を明記します。
   - 付録に「Invalid種別ごとの件数」や「具体例」「一致率」等を示す表・セクションを新設します（データ部分はプレースホルダーやダミー値を入れます）。
   - 「HarmBench ClassifierがgibberishをSafeと正しく判定した」という矛盾する記述を削り、指定された文章に置き換えます。
   - PPLは判定器ではなく補助診断である旨の記述を追加します。

3. **「順位変動表」の新設と再分類の定量化**
   - 実験結果の章に、「Pattern」「Original ASRでの上位手法」「Validity-aware再評価後」「変化の理由」をまとめた順位変動表（Table）を新設します。
   - 全条件中の再分類件数（$N, M, K$）に関する記述を追加します。

4. **構成の整理**
   - **関連研究と比較対象の統合**:
     現在の `\section{関連研究}` とSSTの説明を統合し、`\section{関連研究と比較対象}` に変更します。内部は以下の3節に整理します。
     - `\subsection{Model Mergingと干渉緩和}`
     - `\subsection{Secure Mergeと安全性保持}`
     - `\subsection{比較対象：Fisher比に基づくSST-Merge}`
     ※SSTの数式は最小限にし、詳細は付録へ退避します。
   - **予備実験の扱い**:
     予備実験の記述を「結果」から「動機」へと短縮し、指定された3文程度に圧縮します。
   - **多重ドメインの「勝者なし」の明記**:
     多重ドメインにおいて一貫した勝者がいないことを、評価論文としての重要な知見として実験結果・考察に明記します。

5. **結論（まとめ）の補強**
   - 「まとめ」の最終段落に、指定された文章（MergeAlignがFalse Safeであり、Task ArithmeticやSafeMERGEが有効な候補として残った旨）を追加し、評価論文としての結論を締めます。
