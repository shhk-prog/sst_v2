# 論文の実験セクション改善の振り返り

## 修正の目的
ユーザーの要望「予備実験と本実験の結果がわかりやすくしたい」に基づき、`flmsec.md` 内の実験結果セクションの構造整理と、データの補完を行いました。

## 実施した変更点

### 1. セクションの明確な分割
元の `flmsec.md` では、「予備実験」と「本実験」の記述が混在しており、読者が実験の目的と結果の境界を把握しづらい状態でした。
これを解決するため、セクション6.1を以下の2つのサブセクションに分割し、それぞれの結果と課題を明確にしました。
*   `\subsection{予備実験（Preliminary Experiment）結果}`
*   `\subsection{本実験（Main Experiment）結果と Pareto Trade-off (RQ1)}`

### 2. 空のテーブルへのデータ追加
`flmsec.md` 内で用意されていたものの、データが空だった以下の2つの表について、`secure-merge_統一比較評価論文_改訂版.md` から対応する実データを取り出し、LaTeXの `tabularx` 形式に整形して埋め込みました。

*   **Table 4: 主要マージ手法における詳細評価指標の3 Seeds Average比較**
    *   3ドメイン（`safety+math`, `safety+code`, `safety+medical`）における各手法の Harmful ASR や Valid応答率 などの詳細データを記載しました。
*   **Table 5: 崩壊分析: 臨界点近傍の詳細指標と偽の安全性 (GSM8K対象)**
    *   SST-Merge (提案手法) の $\alpha$ スイープ時の、各臨界点におけるアライメントの挙動と崩壊状態を明示する表を追加しました。
