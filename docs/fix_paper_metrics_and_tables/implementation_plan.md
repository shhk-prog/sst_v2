## Proposed Changes

### 1. Pareto AUCの定義と値の統一
- **対象**: 6.1節、6.3節
- **修正内容**:
  - `Pareto AUC` という単一の呼称を廃止し、2種類の異なるAUCを明記します。
  - 6.1節の `0.945 / 0.912` は **「Raw Pareto AUC」**（元のASR・Utility座標で全応答を含めて積分した面積）として定義・記載します。
  - 6.3節の `0.2935 / 0.2914` は **「Validity-aware Pareto AUC」**（Gibberish除外後の正常・有効応答だけで計算した面積）として定義・記載し、値が異なる理由を明確にします。

### 2. 「3 Seeds Average」表記の修正
- **対象**: 5.4節、6.1節（Table 2タイトルなど）
- **修正内容**:
  - 実データに分散情報がないため、実験設定および表のタイトルから「3 Seeds Average」の記載を削除します。
  - 代わりに、「代表的な単一実行（seed=42）」または「seed=42での比較」と明記し、読者の誤解を防ぎます。

### 3. 主表 (Table 2) の再構成
- **対象**: 6.1節の Table 2
- **修正内容**:
  - 既存の5大ドメイン平均性能比較の表を廃止し、ご要望の列構成（`Method` | `Harmful ASR ↓` | `XSTest過剰拒否 ↓` | `Valid response rate ↑` | `Valid Safety Rate ↑` | `GSM8K ↑` | `HumanEval ↑`）の表に再構成します。
  - ※Q1の回答に基づき、実データまたはダミー値（プレースホルダ）を挿入します。
  - これにより、MergeAlignなどの「見かけ上のASR低下と完全な出力崩壊」を同一列で識別できるようにします。

### 4. 対象手法間の比較条件の明示
- **対象**: 5.4節 Evaluation Protocol & Baselines
- **修正内容**:
  - 「**パレート優先**：各手法について全αまたは全ハイパーパラメータを掃引し、支配されない点のみ比較した。」という比較条件を明確に追記します。
  - `α = NA` の手法（SafeMERGE, LED-Mergingなど）と `α=0.6` 等の手法がどのように比較されているか、読者に誤解を与えないよう明示します。
