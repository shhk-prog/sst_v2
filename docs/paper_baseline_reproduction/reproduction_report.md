# 論文再現実験レポート: model_merging (NeurIPS 2022)

`baseline/model_merging` において実行した再現実験の結果を以下にまとめます。

## 1. 実験設定
- **対象手法**: model_merging (Matena & Raffel, NeurIPS 2022)
- **ターゲットタスク (Target)**: `rte` (ベースモデル: RoBERTa-base)
- **ドナータスク (Donor)**: `mnli`, `mrpc`, `sst-2`, `sts-b`, `qnli`
- **評価指標**: Validation Accuracy (GLUE RTE)
- **マージ手法**:
  - **Isometric Merge**: 重みの単純な線形補間
  - **Fisher Merge**: 各タスクの対角Fisher情報行列を用いた加重平均マージ

---

## 2. 再現実験結果

ターゲットタスク `rte` に対し、各ドナーモデルをマージした際の結果は以下の通りです。

| ドナータスク (Donor) | マージ手法 (Merge Method) | 基準精度 (Base Acc) (1.0, 0.0) | 最高精度 (Best Acc) | 最適係数 (Coeff) (Target, Donor) | 改善幅 |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **mnli** | Isometric | 0.7256 | **0.7401** | (0.86, 0.14) | +0.0145 (改善) |
| | Fisher | 0.7256 | 0.7329 | (0.86, 0.14) | +0.0073 (改善) |
| **mrpc** | Isometric | 0.7256 | 0.7256 | (1.0, 0.0) | 0.0000 (変化なし) |
| | Fisher | 0.7256 | 0.7256 | (1.0, 0.0) | 0.0000 (変化なし) |
| **sst-2** | Isometric | 0.7256 | 0.7256 | (1.0, 0.0) | 0.0000 (変化なし) |
| | Fisher | 0.7256 | **0.7292** | (0.96, 0.04) | +0.0036 (微改善) |
| **sts-b** | Isometric | 0.7256 | **0.7329** | (0.88, 0.12) | +0.0073 (改善) |
| | Fisher * | 0.5271 | 0.5271 | (1.0, 0.0) | 0.0000 (精度低下) |
| **qnli** | Isometric | 0.7256 | 0.7256 | (1.0, 0.0) | 0.0000 (変化なし) |
| | Fisher | 0.7256 | 0.7256 | (1.0, 0.0) | 0.0000 (変化なし) |

### 注記および考察
- **マージによる精度改善**:
  - `mnli` (マルチジャンル自然言語推論) は `rte` (認識含意関係の認識) とタスクの性質が極めて近いため、マージによって `RTE` タスクの精度が **0.7256 から 0.7401 (+1.45%)** へと向上しました。
  - `sts-b` (セマンティックテキスト類似度) との Isometric Merge においても精度向上が見られました。
- **`sts-b` の Fisher Merge における精度低下 (*)**:
  - `sts-b` との Fisher Merge では、Target 係数を 1.0 にしているにもかかわらず精度が **0.5271** まで著しく低下しています。
  - `sts-b` は回帰 (Regression) タスクであり、他の分類 (Classification) タスクとは損失関数や出力層の次元数、Fisher 行列のスケールが異なるため、Fisher 行列の正規化や読み込み時に Target モデルのパラメータへ不適切なスケーリングが適用され、ベース精度自体が破壊された可能性が考えられます。
