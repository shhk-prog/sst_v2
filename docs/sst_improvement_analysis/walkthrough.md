# ウォークスルー: SST-Merge 改善分析と再計画

## 実施内容
* 既存の実験結果（`docs/07_paper/論文.md`）のデータを分析し、SST-MergeがTask Arithmetic等のベースラインに対して明確なパレート優位を示せていない原因を特定しました。
* 「評価指標の不備（過剰拒絶の捕捉漏れ）」、「タスクペアの競合の弱さ（RepliQA等）」、「FIM推定のノイズ」の3つが主要な改善点であることを確認しました。
* 新たな改善アプローチを `implementation_plan.md` としてドキュメント化し、それに基づく実行タスクを `task.md` にリストアップしました。

## 確認された洞察
* 単なるJB ResistanceとRepliQA/AlpacaのROUGEスコアだけでは、既存手法の「見せかけの高スコア」を見破れないため、XSTestやLLM-as-a-Judgeを用いたより厳密なペナルティ評価が不可欠です。

## 次のステップ
* ユーザーからのフィードバックを得た後、評価パイプラインの構築や新規データセットの選定を開始します。
