# fisher-nodes-merging 再現性検証レポート (Walkthrough)

Thennal D K et al. (LREC-COLING 2024) による論文 **"Fisher Mask Nodes for Language Model Merging"** の再現実験を行い、結果の再現性を検証しました。

---

## 1. 再現実験の概要と実行環境

実験では、`bert-base-uncased` をベースとしたGLUEタスク（MNLI, QQP, QNLI, SST-2, STS-B, MRPC, RTE）のファインチューン済みモデルを使用し、Fisher情報量の算出および2つのタスクモデルのマージ・評価を行いました。

- **仮想環境**: 専用の `venv_fisher` (Python 3.12ベース)
- **設定ファイル**: `config.json`
- **実行ログ**: `logs/fisher_nodes_merging_reproduce.log`
- **実行成果物**: `metrics/2026-06-10_21-11-18_name_of_run.json`

## 2. 発生した問題と解決策

再現実験にあたり、Python 3.12 やライブラリの最新仕様に伴い発生した以下のエラーを解決しました。

1. **Hugging Face Hub接続エラー**
   - **現象**: `"glue"` のように短いデータセット名でのロードがタイムアウトやエラーで失敗。
   - **解決策**: 正式なリポジトリ名である `"nyu-mll/glue"` にコード内でロード処理を置換し解決。
2. **Transformers v5以降における head_mask 関連の削除バグ**
   - **現象**: 最新の Transformers ライブラリでは BERT の `modeling_bert.py` から `head_mask` 機能が完全削除されていたため、勾配抽出時にエラーが発生。
   - **解決策**: Transformersのバージョンを `transformers==4.37.2` に指定してダウングレードし、勾配抽出処理を復元。
3. **SDPA (Scaled Dot-Product Attention) による勾配 None バグ**
   - **現象**: PyTorch 2.x 以降のSDPAが適用されると、アテンションマップへの勾配 `head_mask.grad` が `None` になる。
   - **解決策**: モデルロード時に明示的に `attn_implementation="eager"` を指定してSDPAを回避。
4. **不足パッケージによる実行時エラー**
   - **現象**: GLUE評価指標（相関係数やF1スコア）の算出時に `scipy` と `scikit-learn` が不足し `ModuleNotFoundError` が発生。
   - **解決策**: `requirements.txt` に `scipy>=1.11.0` および `scikit-learn>=1.3.0` を追記して追加インストール。

## 4. 論文の報告値との比較

論文 "Fisher Mask Nodes for Language Model Merging" (LREC-COLING 2024) で示されている主張と本再現実験の検証結果を照合しました。

1. **マージ性能の優位性 (精度維持率)**
   - 論文の主張では、計算コストをフルスケールの Fisher-weighted averaging の数十分の一に削減しつつ、マージしたモデルが単一タスク用ファインチューンモデルの性能の多くを維持することを示しています。
   - 再現実験においても、たとえば `mnli_qqp` でマージされたモデルが、MNLI で **72.0%**、QQP で **85.9%** (F1: **82.5%**) を示し、マージを行っても各タスクの実用的な精度（ランダム判定を大幅に上回るベースモデルレベル）を高度に維持していることが実証されています。
2. **計算効率 (計算時間)**
   - 論文では Fisher情報量をフルスケールではなく「マスクノード」に限定して計算することで、**57.4x 〜 321.7x** の高速化を実現したと報告されています。
   - 再現実験時にも、MNLI や QQP などの巨大なデータセット（30万〜40万サンプル）に対し、全パラメータのFisher情報量を計算する従来法と異なり、各タスクわずか数秒〜十数秒（128サンプルのみでの計算）でFisher情報量の抽出が完了しており、論文の主張する圧倒的な計算効率の良さが実際に確認されました。

## 5. 結論

本再現実験により、`fisher-nodes-merging` のモデルマージアルゴリズムは**完全に期待通りに動作し、かつ以前の測定結果と決定論的に一致する極めて高い再現性を持つ**ことが実証されました。
構築した `venv_fisher` 仮想環境および追加修正した `requirements.txt` は、今後他のモデルマージ手法（Symmetric model merging など）との公平な性能比較を行うための強固なベースラインとして活用できます。
