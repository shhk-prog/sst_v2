# 評価タスクおよび指標の評価基準一覧

本プロジェクトで扱っている17個の評価指標について、測定対象、評価基準、およびスコアの高低の意味（高い方が良いか・低い方が良いか）を整理したテーブルです。

| カテゴリ | 評価タスク / 指標 | 測定対象・評価基準 | 望ましい方向 |
| :--- | :--- | :--- | :--- |
| **safety** (安全性) | Harmbench (ASR↓ %) | 有害な指示や敵対的攻撃に対する拒否能力。<br>攻撃成功率（ASR: Attack Success Rate）を測定し、**低いほど安全**であることを示します。 | **低い方が良い (↓)** |
| | Jailbreakbench (ASR↓ %) | 標準的なJailbreak（脱獄）プロンプトに対する攻撃成功率。<br>**低いほど安全**であることを示します。 | **低い方が良い (↓)** |
| | Strongreject (ASR↓ %) | より強力・高度なJailbreak攻撃に対する攻撃成功率。<br>**低いほど安全**であることを示します。 | **低い方が良い (↓)** |
| | Wildjailbreak (ASR↓ %) | 実環境（野生）から収集された多様な敵対的プロンプトに対する攻撃成功率。<br>**低いほど安全**であることを示します。 | **低い方が良い (↓)** |
| **Math** (数学) | GSM8K (Flex EM↑ %) | 小学校レベルの算数・数学の文章題タスク。<br>柔軟な正規表現抽出を用いた完全一致（Flexible Exact Match）率。**高いほど数学的思考力が優秀**であることを示します。 | **高い方が良い (↑)** |
| | Minerva Math500 (Verify↑ %) | 高度な高校・大学レベルの数学問題集。<br>最終回答が正しく抽出され、検証プロセスを通過した割合。**高いほど高度な数学推論能力が優秀**であることを示します。 | **高い方が良い (↑)** |
| **General Chat** (対話) | Alpaca Eval 2 (Win Rate↑ %) | 一般的な対話指示に対する応答品質。<br>GPT-4などの参照モデルとの比較における勝率（Win Rate）を測定し、**高いほど人間らしく自然で高品質な対話が可能**であることを示します。 | **高い方が良い (↑)** |
| **code (data)** (コードデータ) | Evol-Instruct-Code (PPL↓) | コーディング指示テキストの予測の不確実さ。<br>Perplexity（当惑度）を測定し、**低いほどコード指示を言語モデルが流暢かつ自然に理解できている**ことを示します。 | **低い方が良い (↓)** |
| | Evol-Instruct-Code (Sim Score↑) | モデルが生成した応答と正解データとの類似度。<br>Similarity Scoreを測定し、**高いほど正解のコーディング基準に近い適切な応答ができている**ことを示します。 | **高い方が良い (↑)** |
| **code** (コードタスク) | HumanEval (Pass@1↑ %) | Pythonの標準的なコーディング能力テスト（164問）。<br>生成されたプログラムがユニットテストを一発でパスした割合（Pass@1）。**高いほど実用的なプログラミング能力が優秀**であることを示します。 | **高い方が良い (↑)** |
| | MBPP (Pass@1↑ %) | 基本的なPythonプログラミング問題集。<br>ユニットテストを一発でパスした割合（Pass@1）。**高いほどコーディング能力が優秀**であることを示します。 | **高い方が良い (↑)** |
| **Medical (data)** (医療データ) | MedAlpaca (PPL↓) | 医療分野の専門テキストにおける言語モデルの予測の不確実さ。<br>Perplexity（当惑度）を測定し、**低いほど専門的な医療用語や医療文脈を流暢に理解できている**ことを示します。 | **低い方が良い (↓)** |
| | MedAlpaca (Sim Score↑) | 医療関連の指示文に対するモデル生成物と正解データの類似度。<br>Similarity Scoreを測定し、**高いほど医療知識に沿った正しい回答ができている**ことを示します。 | **高い方が良い (↑)** |
| **Medical** (医療タスク) | MedQA (Acc Norm↑ %) | 米国医師国家試験（USMLE）などの医学知識を問う4肢選択問題。<br>標準化された正答率（Accuracy Normalized）を測定し、**高いほど専門的で正確な医学知識を持つ**ことを示します。 | **高い方が良い (↑)** |
| | PubmedQA (Acc↑ %) | 医学文献（PubMed）の要約から「Yes / No / Maybe」で回答する質問応答。<br>正答率（Accuracy）を測定し、**高いほど医学論文の正確な読解・推論能力を持つ**ことを示します。 | **高い方が良い (↑)** |
| **General** (一般指示) | IFEval (Strict Prompt Acc↑ %) | 「特定の文字数で出力する」「特定の書式に従う」などの指示（制約）遵守能力。<br>制約を厳密に守れた割合。**高いほど指示に忠実に従う能力が高い**ことを示します。 | **高い方が良い (↑)** |
| | MMLU (Acc↑ %) | STEM、社会科学、人文科学など多岐にわたる専門知識の選択問題集。<br>正答率（Accuracy）を測定し、**高いほど広範で正確な一般知識・教養を持つ**ことを示します。 | **高い方が良い (↑)** |
