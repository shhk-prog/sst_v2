# 論文全体のブラッシュアップ計画（Abstract〜まとめの一貫性強化）

先ほど第2章・第3章で確立した「SST-Mergeは2つのFisher計量を競合させる最適化問題（GEVP）である」という強固な理論的基盤を、論文全体（Abstract、Introduction、実験考察、まとめ）に波及させ、一貫したストーリーを持つ論文へと全体的にブラッシュアップします。

## Proposed Changes (修正内容)

### 1. Abstract（あらまし）の洗練
- **課題の鋭角化**: 既存のmerge手法を用いると「一般性能が劣化する」という表現を深め、「経験的なベクトル操作や単一の曲率に頼るため、Safety Tax（有用性劣化）を構造的に回避できない」という問題設定に変更します。
- **解決策の明示**: 提案手法が「良性分布（Utilityコスト）」と「有害分布（Safetyゲイン）」という2つの独立したFisherを直接競合させる「一般化固有値問題（GEVP）」であることを明記し、理論の新規性を際立たせます。

### 2. 第1章：Introduction の再構築
- **背景と課題の接続**: Jailbreak攻撃とガードレールの限界を述べた後、Secure Merge（内部パッチ）が必要であることを説明します。その上で、既存のAlignMergeやTask Arithmeticの限界（第2章で書いた「単一計量・ヒューリスティクスの限界」）を端的に先取りして述べます。
- **提案の優位性**: 本研究の貢献（Contribution）として、「最適化原理の導入（GEVP）」と「理論に基づくData-Free Surrogateの構築」の2点を明確にハイライトする段落を追加します。

### 3. 実験結果の考察（4.1 失敗モード分析）の補強
- すでに記述されている「失敗モードA（過剰拒絶）」と「失敗モードB（推論崩壊）」に対して、なぜSST-Mergeがこれらを回避できるのかを「最適化原理に基づく外科的介入（方向選別）を行っているから」という理論と結果を結びつける形で補強します。

### 4. 第5章：まとめ の一貫性確保
- 単なる「手法を提案し、Utility劣化が緩やかであることを確認した」という結論から、「マージを2つの相反する計量の競合として定式化し、Data-Free環境でもその最適化ランキングを維持できることを示した」という、より高い視座での結論にブラッシュアップします。
