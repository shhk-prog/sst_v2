# 既存研究と提案手法のブラッシュアップ計画

先ほど構築した「関連研究と提案手法の接続」をさらに洗練（ブラッシュアップ）させ、既存手法の限界（Research Gap）と本研究の優位性（Contribution）のコントラストをより鮮明に描き出します。

## 課題の背景
先ほどの修正では、10本の先行研究をカテゴリごとに整理し、SST-Mergeへの導入としました。しかし、論文としてさらに説得力を持たせるためには、「既存の優れた手法（例：AlignMerge, SafeMERGE等）がある中で、なぜSST-Mergeが必要なのか」という**限界の指摘と解決策の提示**をより深く・鋭く記述する必要があります。

## Proposed Changes (ブラッシュアップの方向性)

### 1. 関連研究（第2章）の批判的整理の強化
既存研究を単に紹介するだけでなく、それらが抱える**「最適化の視点の欠如」**を明確にします。
- **AlignMergeの限界**: Fisher-Rao幾何を用いてアライメントを保持する先駆的手法だが、あくまで「ベースモデルの単一のFisher計量（または特定のアライメント軸）」に基づくペナルティである点を指摘。安全性と有用性それぞれのデータ分布から得られる**2つの曲率の競合**としては定式化できていないことを明記する。
- **SafeMERGE / LED-Mergingの限界**: 層ごとの選択的マージや活性化に基づく分離でSafety-Utilityの競合を和らげているが、類似度や位置選出のヒューリスティクスに依存しており、「あるTax（性能劣化）の制約下でGain（安全性向上）を理論的に最大化する」ような厳密な方向選別には至っていないことを指摘する。

### 2. 提案手法（第3章）の「最適化の必然性」の強調
SST-Merge（GEVP）が単なるマージ技術の一つではなく、上記限界を解決する数学的必然であることを強調します。
- **2つのFisher計量の競合**: 既存手法が「単一計量空間のペナルティ」や「経験的な重み付け」に留まるのに対し、本手法は「良性分布（コスト）」と「有害分布（ゲイン）」の2つの独立した計量を直接競合させ、その比（一般化Rayleigh商）を最大化するという**最適化問題の定式化**そのものに新規性があることを強く打ち出す。

### 3. Data-Free Surrogateの「積極的意義」の加筆
FIMが計算できないという消極的な理由だけでなく、Data-Free Surrogateの立ち位置を強固にします。
- **理論的基礎付け**: 既存のTIESやTask Arithmeticの拡張は「経験的に機能するタスクベクトルの選別」であるのに対し、Data-Free SSTは「GEVPによる最適化原理（方向選別のためのランキング）」という**確固たる理論的背景から派生したサロゲート**であることを記述し、Data-Free層別マージ（arXiv:2603.21705等）の知見と結びつけて理論の深度を増す。
