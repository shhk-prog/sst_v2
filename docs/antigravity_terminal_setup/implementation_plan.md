# アンチグラビティのターミナルコマンド実行設定

アンチグラビティ（AIエージェント）の機能をターミナルから最大限に活用するための設定と使用方法を案内します。

## ユーザーレビューが必要な事項
- `agy` コマンドがすでにパスに通っていることを確認していますが、システム全体のパス（例：`/usr/local/bin`）へのシンボリックリンク作成が必要かどうか。
- AIエージェントによるコマンド実行の「自動承認（Auto-approval）」設定を有効にするかどうかの判断。

## 提案される変更

### 1. ターミナル連携の解説ドキュメント作成
ターミナル上でAIを活用するための3つの主要な方法について解説したドキュメントを `docs/antigravity_terminal_setup/` に作成します。

- **`agy` コマンドの活用**: ターミナルからファイルやフォルダをアンチグラビティIDEで開く方法。
- **ターミナル内AI生成 (`Ctrl+I` / `Cmd+I`)**: ターミナル上で直接自然言語からコマンドを生成・実行する方法。
- **対話モード（Cmd+L）からの出力管理**: チャットで提案されたコマンドを、サイドパネルではなくメインのターミナルパネルで実行・表示させる方法の解説。
- **エージェントのコマンド実行管理**: AIエージェントが提案するコマンドの承認フローと自動承認設定について。

### 2. シェル統合の確認と設定（必要に応じて）
現在のシェルの設定ファイル（`.bashrc` や `.zshrc`）に `agy` のエイリアスやシェル統合スクリプトを追加する手順を案内します。

## 検証計画
### 手動検証
- ユーザーにターミナルで `Ctrl+I` を試してもらい、AIが反応することを確認する。
- `agy .` で現在のディレクトリが正しく開けるか確認する。
