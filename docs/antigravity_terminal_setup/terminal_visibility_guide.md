# アンチグラビティ：ターミナル出力の可視化ガイド

対話モード（Cmd+L）やエージェントが提案するコマンドの実行結果を、メインのターミナルパネルで確認・管理する方法について説明します。

## 1. ターミナル内AI (`Ctrl+I` / `Cmd+I`) の活用
最も確実な方法は、**ターミナルパネルにフォーカスを置いた状態で `Ctrl+I`** を押すことです。
- ここで入力した指示に基づいて生成されたコマンドは、通常のシェル履歴と同様にターミナル上に表示され、実行結果もそのままターミナルに残ります。
- 以前の「コマンドがそのままターミナルで実行される」感覚に一番近いのはこの機能です。

## 2. エージェント用ターミナルタブの確認
対話モード（Cmd+L）でエージェントがコマンドを実行する場合、デフォルトでは新しいターミナルタブが作成されることがあります。
- 画面下部の「Terminal」パネルを確認し、右側のドロップダウンまたはタブ一覧に「Agent Task」や「bash」などの新しい項目が増えていないか確認してください。
- 実行中のコマンドや詳細な出力は、その専用タブにリアルタイムで表示されます。

## 3. 出力が見にくい場合の対策
もし対話画面の「Run」ボタンの結果がチャットバブル内だけで完結してしまい、ターミナルに表示されない場合は、以下の設定や運用を検討してください。

- **自動承認の設定**: 設定 (`Cmd + ,`) > `Agent` > `Terminal: Auto Execution` を変更することで、承認フローを簡略化できます。
- **明示的な指示**: チャットで「以下のコマンドをターミナルで実行して」と指示することで、エージェントがターミナルツールを使用して実行するよう促せます。

## 4. 便利なショートカット
- **`Cmd + J`**: 下部のパネル（ターミナル含む）の表示/非表示を切り替えます。
- **`Cmd + Shift + C`**: 現在のファイルをターミナルで開きます。
