# flmsec.tex 評価指標および実装詳細の修正

## 目的
査読者が実験および評価手法を完全に再現できるよう、`flmsec.tex` 内に存在する曖昧な表現、誤解を招く名称、および不足している学習・評価パラメータをコードの実装に基づき正確に追記・修正する。

## 修正内容の要約
1. **Safety Aveの向きと定義の明確化**
   - 誤解を招く「Safety Ave [Refusal-Filtered]」を「Safety Ave [Conditional ASR]」に統一し、低いほど良いことを明示。
   - 「Safety Ave [Harmful Content]」が対象4ベンチマークのOriginal ASRのマクロ平均であることを明記。
2. **Validity-aware Pareto AUC の数式化**
   - 積分範囲（$x \in [0, 1]$）、$x$（ASR）、$y$（正規化有用性）および台形則による計算を記述し、パレート前線の抽出方法を明確化。
3. **コード生成（HumanEval等）のパラメータ明示**
   - 評価コード (`eval_utility.py`) の実装に基づき、「1問につき十分なサンプル数」を「$n=1$ 個のシングルサンプル」へ変更し、「温度 $T=0$ (greedy decoding)」「ベンチマーク既定の停止条件」を明記。
4. **AlpacaEval 2のJudgeと件数の統一**
   - 「評価対象100または全件」を「評価対象100件」に統一。
   - 曖昧な「GPT-4.1 Judge等」を「\texttt{gpt-4-1106-preview}」などの具体的なバージョン名に修正。
5. **安全モデルの学習データ・ハイパーパラメータの追記**
   - スクリプト (`fine_tuning.py`) から、LoRAランク(16)、alpha(32)、学習データ（TrustLLMの有害プロンプト＋定型拒否文）、エポック(3)、バッチサイズ(4) などを追加。
6. **「各ベンチマーク最大320件」の表と矛盾解消**
   - Table 2を修正し、「データセット規模」と「本研究の評価件数（最大320件に制限されたもの）」の列を分離して誤読を防ぐ。
7. **文章のみの微修正**
   - "safety-aware" を "Safety-aware" にキャピタライズ。
   - "結論づけない" となるような末尾の文の調整。
   - Gibberish Nや安全な応答の区別に関する表現の修正。

## 完了状態
上記すべての変更をファイルに直接適用し、完了済み。
