## 2. 分析・考察

### ① Model 1 (Math) の挙動と「破滅的忘却」
* **数学性能**: 数学FTを行ったモデルであるにもかかわらず、GSM8Kが `0.7672 -> 0.6550`、Minerva Mathが `0.2696 -> 0.1790` と、ベースモデルに比べて性能が大きく低下しています。
* **致命的な劣化**: 最も顕著なのは **TeleQnA における正解率の大幅な低下 (0.5037 -> 0.0566)** です。多肢選択問題であるにもかかわらず正解率が5%台となっており、これはランダムに回答した場合の期待値（選択肢数が3〜5つのため通常20〜33%程度）を大きく下回っています。
* **原因分析**: FT学習時に特定の回答出力フォーマットに固執するような過学習が起きた、あるいは多肢選択の回答指示（指示追従能力）が完全に破壊される「破滅的忘却（Catastrophic Forgetting）」が発生したと考えられます。数学タスクのデータセット特性と学習率の組み合わせが不適切だった可能性があります。

### ② Model 2 (Coding) の意外なシナジー
* **コーディング性能**: ターゲットである MBPP (pass@1) は `0.5700 -> 0.5320` と微減しました。
* **通信・知識問題での躍進**: 一方で、**TeleQnA（通信専門ドメイン）の総合正解率が 0.5785** となり、ベースモデル (0.5037) および他のすべてのFTモデルを凌駕する最も優れた結果を示しました。
* **原因分析**: コーディング用データセットによるFTが、モデルの論理的推論力や構造化されたテキスト（仕様書や規格書など）を理解・処理する能力を向上させ、TeleQnA のような専門的かつ論理的な多肢選択問題において強力なシナジーを発揮したと推測されます。

### ③ Model 3 (Medicine) の堅実な成果
* **医学性能**: ターゲットタスクである **PubMedQA (acc) が 0.7460 -> 0.7660 へと向上**し、アライメントに成功したことが確認できます。
* **他タスクへの影響**: TeleQnA でも `0.5037 -> 0.5345` と性能が向上しており、特定の専門知識タスクでのFTが類似した記述的知識問題に対してポジティブな知識転移（Knowledge Transfer）を起こしたと考えられます。

## 3. 次のアクション・推奨事項

1. **Model 1 (Math) の再チューニング**:
   - 学習率 `2.0e-5` は数学タスクにとって大きすぎた（あるいは小さすぎた）可能性、もしくは学習データ（プロンプトフォーマット）が多肢選択等の指示を壊すものであった可能性があります。
   - 以前行われた `lr 2.0e-4` の結果などと比較し、より適切なハイパーパラメータや正則化（あるいは学習データに一般指示をブレンドする）を検討すべきです。
2. **Model 2 (Coding) のさらなる検証**:
   - コーディングタスクそのものの性能（MBPP）が微減した原因を追究するとともに、TeleQnA における急激な性能向上をモデルマージなどに活かす方法を検討します。
