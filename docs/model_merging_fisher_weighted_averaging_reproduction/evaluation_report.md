# Fisher-Weighted Averaging 評価レポート

## 実験概要
NeurIPS 2022 「Resolution of Multiple Tasks in Model Merging」の主要手法の再現実験結果のレポートです。
ターゲットモデルを **RTE (Recognizing Textual Entailment)** とし、他の5つのタスク (MNLI, MRPC, SST-2, STS-B, QNLI) のモデルをそれぞれドナーとしてマージし、ターゲットタスク(RTE)の推論精度(Accuracy)の変化を測定しました。

マージの手法として以下の2つを比較しました。
1. **Isometric Merge**: 単純なスカラー係数による重み付け和。
2. **Fisher Merge**: 各モデルの対角Fisher情報行列を用いて、モデルパラメータごとの重要度を考慮した重み付け和。

---

## 評価結果サマリー

ベースラインとなるRTE単体モデルの初期Accuracyは **`0.7256`** です。

| ドナーモデル | マージ手法 | 最高精度 (Accuracy) | 最適な混合比率 (Target, Donor) | 精度向上 |
| :--- | :--- | :--- | :--- | :--- |
| **MNLI** | Isometric | 0.7401 | (0.88, 0.12) | +0.0145 |
| | Fisher | 0.7329 | (0.86, 0.14) | +0.0073 |
| **STS-B** | Isometric | 0.7329 | (0.88, 0.12) | +0.0073 |
| | Fisher | 0.5271 (※1) | (1.0, 0.0) | 悪化 |
| **MRPC** | Isometric | 0.7256 | (1.0, 0.0) | 変化なし |
| | Fisher | 0.7256 | (1.0, 0.0) | 変化なし |
| **SST-2** | Isometric | 0.7256 | (1.0, 0.0) | 変化なし |
| | Fisher | 0.7256 | (1.0, 0.0) | 変化なし |
| **QNLI** | Isometric | 0.7256 | (1.0, 0.0) | 変化なし |
| | Fisher | 0.7256 | (1.0, 0.0) | 変化なし |

*(※1) STS-Bは唯一の「回帰タスク」であり、Fisher行列のスケールや分布が他の分類タスクと大きく異なるため、Fisher Mergeの際にTargetモデルのパラメータを破壊してしまった（ベース精度自体が0.5271へ低下した）と推測されます。*

## 考察

### 1. タスク間の相性 (Task Transferability)
RTE（含意関係認識）に対して、MNLI（自然言語推論）をマージした場合に明確な精度の向上が見られました。RTEとMNLIはタスクの性質が非常に似ているため、ドナーモデルの持つ知識がターゲットモデルの性能を引き上げたと考えられます。
逆に、MRPC (パラフレーズ識別) や SST-2 (感情分析) などの異なる性質のタスクをマージしても、最適な混合比率が `(1.0, 0.0)`（すなわちドナーを一切混ぜない状態）となり、性能向上には寄与しませんでした。

### 2. Isometric Merge と Fisher Merge の比較
今回の実験設定（RoBERTa-baseを用いた2モデル間のマージ）では、MNLIドナーにおいて単純な **Isometric Merge (+0.0145)** の方が **Fisher Merge (+0.0073)** よりも高い性能改善を示しました。
論文ではFisher Mergeの優位性が主張されていますが、以下の理由により今回の結果になったと考えられます。
- ターゲットモデルとドナーモデルが1対1であるため、パラメータ干渉が比較的少なく、単純な線形補間（Isometric）でも十分な解空間を探索できた。
- ベースモデルが小規模（`roberta-base`）であり、タスク間の競合が大規模モデル（または多数のモデルの同時マージ）ほど深刻ではなかった。

### 3. 次のステップへの提案
この実験から、モデルマージにおいては「どのタスク（モデル）を選ぶか」という**タスクの類似性**が最も重要であることがわかります。
もしFisher Mergeの真価（パラメータ間の干渉を防ぐ効果）をより明確に確認したい場合は、以下のアプローチが考えられます。
- 3つ以上のモデルを同時にマージする。
- 全く異なるドメインのタスクモデルを多数結合する。

### 4. 論文結果との比較
元の論文（Matena and Raffel, 2022）では、Fisher-Weighted Averaging（Fisher Merge）は単純な平均化（Isometric/Isotropic Merge）と比較して一貫して性能が高く、特に **RTE（ターゲット）と MNLI（ドナー）の組み合わせにおいて最大の性能ギャップ（Fisherの優位性）** が確認されたと報告されています。
具体的には、論文内のRoBERTaを用いた実験において、MNLIをドナーとしたRTEタスクにおいて Fisher Merge を用いることで、Isotropic Merge よりも **最大で約 2.2 ポイント (2.2%)** 高い精度向上が得られたと記載されています。

しかし今回の再現実験では、同じペア（RTE + MNLI）において以下の逆の結果となりました。

| 評価元 | マージ手法 | 精度向上幅 (vs RTE単体) | 結論の差異 |
| :--- | :--- | :--- | :--- |
| **再現実験 (本実験)** | Isometric Merge | **+1.45%** (+0.0145) | **Isometric の方が優秀** |
| | Fisher Merge | +0.73% (+0.0073) | |
| **論文報告 (Matena et al.)** | Isometric Merge | (基準値) | |
| | Fisher Merge | **+2.2%** (vs Isometric) | **Fisher が圧倒的に優秀** |

すなわち、論文の主張とは逆に **Isometric Merge の方が Fisher Merge よりも精度向上幅が大きい** 結果となりました。
この差異が生じた原因として、以下の要因が推測されます。
1. **ハイパーパラメータや探索空間の違い:** 我々の実験ではあらかじめ定義された等間隔の固定ステップの係数で探索を行いましたが、論文ではより細かな係数チューニングや、異なる正則化係数が用いられていた可能性があります。
2. **モデルアーキテクチャの規模:** 本実験では `roberta-base` を用いましたが、論文で示された劇的な性能改善（~2.2ポイントのギャップ）は `roberta-large` などのより大規模でパラメータ干渉が起きやすいモデルにおいて顕著に表れる特性である可能性があります。
3. **データ前処理の差異:** 新しいHugging Faceライブラリでのパディング処理の挙動変更など、入力データの扱いの微小な違いがFisher行列の対角要素の推定に影響を与えた可能性があります。

結論として、タスク適応におけるマージの有効性自体は再現できましたが、「Fisher行列による重み付けが常に単純平均を上回るわけではない」という実践的な知見が得られました。

以上、Fisher-Weighted Averaging手法の再現と評価レポートとなります。
