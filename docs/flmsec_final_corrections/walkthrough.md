# 論文原稿（flmsec.tex）追加修正のWalkthrough

ご承認いただいた実装計画に基づき、`v3/docs/flmsec/flmsec.tex` に対する数式および実験設定の詳細化をすべて完了しました。

## 1. AUC計算の端点補完とUtility正規化の厳密化
- 既存の「前値保持」という表現を改め、得られたパレート点の最小・最大の安全性座標 \((s_1,u_1)\) および \((s_K,u_K)\) を用いて、補完点 \((0,u_1)\) および \((1,u_K)\) を追加し、線形補間して台形則積分する実装仕様を数式的に正確に記述しました。
- Utilityの正規化が「各タスクの評価値（0〜100%）を100で割り、0から1の範囲にクリップ」する処理であることを明記しました。
- 未観測の極端な安全性領域への水平延長が強い仮定となる点に配慮し、限界事項として「端点補完を行わず実測された安全性範囲のみで計算した保守的なAUCの結果も付録に報告する」旨を追記しました。

## 2. Fisher推定式のトークン配分表現の修正
- 「入力プロンプトと応答の両方を含む全有効トークン」に損失を適用する事実を正確に表現するため、連結トークン列 $z_{n,t}$ を用いた自己回帰的な対数尤度の和として尤度式を修正しました。
  $$ \ell_n(\theta) = -\sum_{t=1}^{T_n} \log p_\theta(z_{n,t}\mid z_{n,<t}) $$

## 3. LoRA / Safety FT設定の完全な詳細化
- 実装コード（`fine_tuning.py`）に基づき、以下の訓練ハイパーパラメータを網羅的に追記しました。
  - warmupなし(0)、weight decay=0
  - gradient clipping（最大ノルム1.0）
  - オプティマイザ: AdamW (\(\beta_1=0.9, \beta_2=0.999, \epsilon=10^{-8}\))
  - トークナイザ設定: ベースモデルの既定を用い、特定のchat templateは適用せず生テキストとして学習
  - バリデーションデータによるcheckpoint選択は行わず、最終エポックのモデルを採用

## 4. Gibberish判定と安全性判定の分離
- 単なる「外部評価器を用いず...」という記載が有害判定自体にも適用されていると誤解されるのを防ぐため、「Gibberish判定には外部評価器を用いずヒューリスティクスのみを用いた。一方、有害要求への追従判定には各安全性ベンチマークの既定評価器またはスクリプトを用いた」と明確に分離して記述しました。

## 5. 320件のサンプリング制限（Limitations）の正確化
- MMLUにおいてはタスク毎の均等抽出により320件を用いた事実を追記し、単なる「先頭320件」という表現を正確に修正しました。
