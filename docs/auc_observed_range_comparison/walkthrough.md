# AUCセクションの最終確定と仕上げ

ご指摘いただいた最終確認ポイント（4点）について、以下の通り修正を完了しました。

## 1. `\pm 0.00000` の解釈と桁数揃え
SST、Data-Free SST、およびTIESの分散が0であった理由について、計算に用いたパレート点がseed間で同一であったことを表注に明記しました。
また、Observed-range AUC の微小な値が誤解されないよう、科学表記（例: `6.0\times 10^{-5}`）に統一し、表の視認性と精度を向上させました。

## 2. \(s_{\min}, s_{\max}\) の集約方法の明示
表注に「各seedにおける最小値・最大値を平均した値である」旨を追記し、AUCと同じ集約単位であることを明確にしました。

## 3. Task Arithmetic の実測値の公開と解釈
「支配されない点が1点のみであった」という理由だけで除外するのではなく、その1点の数値を小表（Table 2）として公開しました。
さらに、本文中にてその数値の意味合いを慎重に解釈する以下の段落を設けました。
> 「Task Arithmeticは評価した範囲でValid Safety Rate 1.000を達成した一方、対応する有用性は0.078に留まった。したがって、当該点は安全性と有用性の両立ではなく、有用性を大きく犠牲にした安全性側の極端な点として解釈される。」

## 4. AUC算出に用いた Utility の定義と表現の修正
AUCセクションの冒頭に、Utility が「主要ベンチマークの正規化スコアの算術平均であり、PPLやSimilarity Scoreは補助指標として別途扱う」という定義を明記しました。

また、以下の不正確な表現をより適切なものへ置き換えました。
* 「真の安全アライメントとを決定論的に区別するため」 → 「安全性評価と応答有効性を事前定義した規則に基づいて分離して報告するため」
* 「正常応答のみに基づくValidity-aware Pareto AUC」 → 「Valid Safety Rateに基づくValidity-aware Pareto AUC」
* 「有効応答を保ちながら安全性を改善する挙動は…」 → 「有効応答を保ちつつ高いValid Safety Rateを達成する挙動は…」

これでAUCセクションは査読に対しても堅牢な状態になりました。ご確認よろしくお願いいたします。
