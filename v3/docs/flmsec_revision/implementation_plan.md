# flmsec_standalone_nosst2.tex のリファクタリング計画

本計画は、`flmsec_standalone_nosst2.tex` に存在する「AI生成特有の冗長性・均質性」「表と本文の数値の不整合」「実証的詳細の不足」を解消するための修正方針をまとめたものです。

## Goal Description

論文全体を通して頻出する「ASR単独では区別できない」「VRR/VSRを併記すべき」という同趣旨の繰り返しを整理し、結論先行・接続詞過多な「AI構文」を自然な学術論文の文体に修正します。また、本文中の数値誤りを修正し、valid/invalidの判定基準や統計的根拠（サンプル数・分散）を明記することで、論文としての実証的説得力を向上させます。

## Open Questions

> 以下の点について、実装を進める前にフィードバックをお願いいたします。

1. **引用の検証範囲について**: 
   Referencesには75件の文献が含まれています。すべてをWeb検索で検証すると膨大な時間がかかるため、特に新規性が高く誤りやすい**近年（2023〜2025年）の主要な関連研究（Model MergeやSafety関連の[1]〜[16]や[19]〜[24]など）**に絞って重点的に検証・修正を進めてもよろしいでしょうか？
2. **valid/invalid判定の一致度について**: 
   現状の付録の記述を見る限り、valid/invalidの判定は「空出力」「一意単語20%未満」などのヒューリスティクス（スクリプト）による決定論的な判定であると推測されます。この場合、「人間アノテータによる判定ではないため評価者間不一致（Inter-rater agreement）は発生しない（またはLLM as a Judgeの複数回実行の一致度を指す）」という前提で記述を補強しても事実に合致しますでしょうか？
3. **ファイルの保存場所について（ユーザールール）**:
   本計画書を含むドキュメントは、システム要件上一時的にシステムフォルダに作成されていますが、完了時に `docs/flmsec_revision/` などのプロジェクト内フォルダにコピーして保存します。フォルダ名にご希望はありますでしょうか？

## Proposed Changes

### 論文全体の修正 (flmsec_standalone_nosst2.tex)

#### [MODIFY] [flmsec_standalone_nosst2.tex](file:///Users/saki/lab/src/sst_v3/docs/flmsec/flmsec_standalone_nosst2.tex)

1. **数値の訂正（Section 4.1）**
   - 表2の数値に合わせて、本文中の Task Arithmetic (safety+code) の数値を修正します。
     - Conditional ASR: 30.53% → **60.91%**
     - VSR: 66.18% → **36.94%**

2. **実証的詳細の明記と主張の根拠付け（Section 3 & 4）**
   - 「本研究の予備実験でも…観測された」といった記述を、「予備実験（各N=320等）において、Gibberish Ratioが高い条件ではRaw ASRが0%または100%に二極化する極端な分散が観測された」のように、サンプル数や統計的根拠を伴う記述に修正します。
   - Section 3.2 (評価プロトコル) に、付録にある valid/invalid の具体的な判定規則（空出力、5単語以上かつ一意単語20%未満、等）の要約を追記し、決定論的スクリプトによる判定であること（例外処理・一致度の考え方）を明記します。

3. **冗長表現と繰り返し構造の削減（Introduction, Section 4, Conclusion）**
   - 「本研究は〜を示す」「したがって〜する必要がある」といった定型的な文体を散らし、文体の揺れを持たせます。
   - Introduction と Conclusion で繰り返されている「ASR単独では区別できない」「VRR/VSRを導入する」という説明を、Introductionでは「課題提起と提案アプローチ」に、Conclusionでは「得られた結果の意義と今後の課題」に役割を明確に分け、重複を削ります。
   - Section 4 の小見出しの重複感を整理します。

4. **引用元の検証と修正（References）**
   - 主要な関連研究についてarXiv番号、会議採択状況、著者名、年を検証し、ハードコードされている参考文献リストの書誌情報を最新の正確なものに更新します。
