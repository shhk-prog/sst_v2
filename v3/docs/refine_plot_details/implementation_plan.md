# プロットの詳細改善 (凡例の統一・Dot Plot化)

## 概要
グラフの視覚的な一貫性を高め、誤解を招きにくい表現にするための細かい改善を行います。

## 変更内容
1. **凡例(Legend)の順序統一**:
   - パネル(b) の凡例が `SST, Data-Free, DELLA, TIES` となっているのを修正し、パネル(a)と同じ `SST-Merge, Data-Free SST, TIES, DELLA` の順序に合わせます。
2. **パネル(c) のドットプロット化**:
   - x軸がtruncateされている（0から始まっていない）棒グラフは、差を強調しすぎて誤解を招くリスクがあるため、`ax3.barh` を削除し、代わりにドットプロット（各カテゴリに対する点 `o` と、必要に応じて薄いガイドラインの表示）に変更します。
   - `ax3.plot(values, names, 'o', ...)` などを活用し、同じ位置にテキストラベル（スコア）も付与します。
