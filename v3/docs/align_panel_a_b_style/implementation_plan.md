# パネルaとbのレイアウトおよびY軸の統一

## 概要
パネル(a)と(b)の見た目をさらに揃えるため、標準偏差の帯を削除し、Y軸の範囲（スケール）を統一します。また、グラフ間の横幅の比率を同じにして全体の大きさを揃えます。

## 変更内容
1. **グラフの大きさを揃える**:
   - `gridspec.GridSpec` の `width_ratios` を `[1.4, 1, 1]` から `[1, 1, 1]` に変更します。
2. **標準偏差 (fill_between) の削除**:
   - パネル(a)およびパネル(b)の描画ループ内にある `ax1.fill_between` と `ax2.fill_between` の呼び出しを削除します。
3. **Y軸の統一**:
   - `ax1.set_ylim` と `ax2.set_ylim` の範囲を `(-5, 125)` に統一し、両者のY軸スケールを揃えます。
