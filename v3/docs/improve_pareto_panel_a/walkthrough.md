# パネル(a) の視覚的改善内容の確認 (Walkthrough)

## 修正内容

`generate_three_panel_plot.py` のパネル(a)部分に対し、以下の視覚的な改善を行いました。

### 1. SSTとBaselineの視覚的区別
- **SST (Diagonal SST / Data-Free SST)**: 
  - 線の太さを `lw=3.2`、マーカーサイズを `ms=6` とし、太く目立たせました。
  - 軌跡上（各マーカー間）に $\alpha$ の増加方向を示す矢印 (`-|>` スタイル) を追加しました。
  - 始点 ($\alpha=0$) は白抜きの丸 (`s=90, facecolor="white"`) に、終点 ($\alpha=1$) は星印 (`s=140, marker="*"`) に変更しました。
  - 中間点のラベルを廃止し、始点・終点のみにそれぞれ $\alpha=0$, $\alpha=1$ のラベルを付与しました。
- **Baseline (DELLA / TIES)**:
  - 矢印を削除し、薄い線 (`.-`, `lw=1.5`, `ms=4`, `alpha=0.6`) に変更しました。これにより、背景情報としての役割を強め、メインのSST手法がより際立つようにしました。

### 2. 軸ラベルと不要な要素の整理
- **Better方向の組み込み**: 
  - 以前存在していた図の右下の「Better」の矢印を削除しました。
  - 代わりに、X軸ラベルを `Utility (GSM8K Acc %)  →`、Y軸ラベルを `Harmful ASR (%)  ↓` に変更し、軸自体に方向性を持たせました。
- **Invalid utilityの調整**:
  - `Invalid utility` 領域を示すグレーの背景塗りつぶしを削除し、境界を示すグレーの破線のみ残しました。
  - ラベルのフォントサイズを小さくし、「Invalid」のみの表記に変更しました。

### 3. Baseline collapse の視覚化
- ユーティリティが崩壊する方向を明確にするため、「Baseline collapse」というテキストとともに、その方向を示すシンプルな矢印を `x=6.0 -> 2.0` の位置に追加しました。

## 確認事項
スクリプトを実行し、`pareto_three_panel.png` が正常に出力されること、および上記すべての変更が意図通りにパネル(a)へ反映されていることを確認しました。
