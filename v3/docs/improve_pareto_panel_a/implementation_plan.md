# Pareto パネル(a) の視覚的改善

## 概要
`generate_three_panel_plot.py` のパネル (a) の描画コードを修正し、SST手法とBaseline手法の軌跡の対比をより明確にする。

## 変更内容
1. **SSTの強調**: 
   - 線の太さを 3.2 に変更し、マーカーを `o-` にする。
   - `alpha` の増加方向を示す矢印(`annotate` の `-|>`) を SST のみに描画する。
   - 始点 (`α=0`) はサイズ90の白抜き丸、終点 (`α=1`) はサイズ140の星印 (`*`) で強調する。
   - ラベルを `\alpha=0`, `\alpha=1` とシンプルにする。
2. **Baselineの弱化**:
   - `DELLA`, `TIES` は矢印なしの薄い線 (`.-`, `lw=1.5`, `alpha=0.6`) に変更する。
3. **軸とレイアウトの整理**:
   - 孤立していた `Better` 矢印を削除し、X軸・Y軸のラベル自体に `→`, `↓` を付与して方向性を示す。
   - `Invalid utility` 領域のグレーの背景 (`axvspan`) を削除し、グレーの破線 (`axvline`) と小さめのテキスト (`fontsize=9`) のみにする。
   - `Baseline collapse` を示す矢印(`->`)とテキストを追加する。
