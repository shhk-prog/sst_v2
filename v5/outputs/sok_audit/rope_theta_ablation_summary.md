## 4. 因果切り分けの結論（草稿 5.3 節用）

- **`DARE`**: `rope_theta` を `1,000,000` に修正しても文字化け率は **100.00% → 99.68%**（拡張 VRR **0.00% → 0.32%**）、Code Avg **0.00% → 0.00%** のままで完全に崩壊したままだった。
- **`fp16 SST (v3)`**: `rope_theta` を `1,000,000` に修正しても文字化け率は **91.36% → 81.50%**（拡張 VRR **7.63% → 15.89%**）、Code Avg **0.00% → 0.00%** のままであり、わずかに非文字化け応答が増えたものの依然として VRR ≥ 80% 基準を大きく下回り、コード生成不能のままだった。
- **`Task Arithmetic`**: 元々文字化けが少なかった TA でも、文字化け率は **1.88% → 1.82%**（拡張 VRR **92.83% → 92.03%**）、Code Avg は **4.53% → 3.59%**（HumanEval 0.00% → 0.00%、MBPP 9.06% → 7.19%）にとどまり、WizardCoder 単体（21.03%）には遠く及ばない。
- **結論**: `safety+code` の壊滅的な文字化け・能力崩壊は **`rope_theta` の設定取り違えだけでは説明できず、異系統モデル（CodeLlama × Llama-2）の重み混合そのものが主因**であることが因果的に確定した。
